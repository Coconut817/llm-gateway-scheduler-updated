# Prompt 与 Response

当前 baseline 将每行完整 `prompt.messages` 作为一次输入，外层 `response` 单独作为本次输出，不展开历史回合。读取与 token 口径见 [架构说明](../../docs/architecture.md)，接入自己的数据见 [运行说明](../../docs/running.md)。历史 Stage 1 会展开合格 assistant，不能将两种请求数量混为一谈。

`prompt回答.jsonl` 包含 3,168 条非流式问答配对，每行只包含两个字段：

- `prompt`：请求内容对象。`messages` 保存完整消息数组及角色顺序；存在工具上下文时，同时包含原有的 `tools`、`tool_choice`、`parallel_tool_calls`。
- `response`：同一次调用的回答文本，结束原因为 `stop`。

格式示例：

```json
{"prompt":{"messages":[{"role":"user","content":"请解释二分查找。"}]},"response":"二分查找适用于有序数据……"}
```
