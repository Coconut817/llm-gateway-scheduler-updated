# 路由实验数据说明

这组文件是保留的历史网关观测数据。当前 baseline 使用自行配置的模拟端点，不自动读取这组流量或容量。两类数据的关系见 [架构说明](../docs/architecture.md)，未来接入边界见 [扩展说明](../docs/extensions.md)。

## 数据概览

数据包含 Model Gateway 线上调用的脱敏行为记录，以及端点、模型、价格和容量配置，可用于路由算法、流量回放、失败重试分析、容量模拟和成本估算。

本批数据包含：

- 24,559 条调用记录；
- 25,319 条上游尝试记录；
- 13 个网关端点；
- 73 组端点—模型配置；
- 103 个价格档位；
- 容量配置包含 RPM、TPM 和并发字段；没有可用值时记为 `null`。

所有 JSONL 文件均为 UTF-8 编码，每行一个 JSON 对象。`null` 表示该字段没有可用值或尚未配置。

## 文件一：流量记录.jsonl

一行对应一次网关调用。每条记录包含请求级信息，并通过 `attempts` 数组包含该调用下的上游尝试明细。

示例：

```json
{
  "request_id": "req_000002",
  "user_id": "user_000016",
  "target_model": "模型S",
  "is_stream": true,
  "arrival_at_ms": 412126.792,
  "finished_at_ms": 418911.203,
  "elapsed_ms": 6784.411,
  "gateway_result": "completed",
  "http_status": 200,
  "input_tokens": 79500,
  "output_tokens": 128,
  "cache_hit_tokens": 77824,
  "first_token_at_ms": 3778.0,
  "final_endpoint_id": "端点L",
  "upstream_model": "模型K",
  "stream_status": "ok",
  "stream_end_reason": "done",
  "attempt_count": 1,
  "quality_flags": [],
  "usable_for_token_workload": true,
  "usable_for_full_attempt_timing": true,
  "attempts": [
    {
      "request_id": "req_000002",
      "attempt_id": "req_000002_attempt_01",
      "attempt_index": 0,
      "retry_index": 0,
      "endpoint_id": "端点L",
      "target_model": "模型S",
      "upstream_model": "模型K",
      "selected_at_ms": 414468.529,
      "sent_at_ms": 414483.77,
      "transport_returned_at_ms": 418178.588,
      "response_headers_at_ms": 418178.588,
      "finished_at_ms": 418911.203,
      "output_tokens": 128,
      "first_token_at_ms": 3694.874,
      "result": "success",
      "http_status": 200,
      "upstream_http_status": 200,
      "outbound_observed": true,
      "outbound_event_count": 1,
      "quality_flags": []
    }
  ],
  "attempts_observed_count": 1,
  "attempts_outbound_observed_count": 1,
  "attempt_join_status": "joined"
}
```

字段说明：

- `request_id`：调用编号。
- `user_id`：脱敏用户代号。
- `target_model`：请求侧模型代号。
- `is_stream`：是否流式请求。
- `arrival_at_ms`：请求到达时间，相对窗口起点的毫秒值。
- `finished_at_ms`：请求结束时间，相对窗口起点的毫秒值。
- `elapsed_ms`：网关记录的请求耗时。
- `gateway_result`：网关最终结果。
- `http_status`：网关返回的 HTTP 状态。
- `input_tokens`、`output_tokens`、`cache_hit_tokens`：输入、输出和缓存命中 token 数。
- `first_token_at_ms`：流式请求的首 token 延迟代理值，取首响应延迟值，单位为毫秒；非流式请求为空。
- `final_endpoint_id`：最终使用的端点代号。
- `upstream_model`：最终可识别的上游模型代号。
- `stream_status`、`stream_end_reason`：流式状态和结束原因。
- `attempt_count`：请求侧记录的尝试次数。
- `quality_flags`：数据质量标记。
- `usable_for_token_workload`：是否适合 token 工作负载分析。
- `usable_for_full_attempt_timing`：是否具备完整尝试时序分析条件。
- `attempts`：该请求下的上游尝试数组。
- `attempts_observed_count`：已关联的尝试记录数。
- `attempts_outbound_observed_count`：有出站证据的尝试记录数。
- `attempt_join_status`：请求与尝试记录的关联状态。

`attempts` 内字段说明：

- `attempt_id`：尝试编号。
- `attempt_index`：从 0 开始的尝试序号。
- `retry_index`：从 0 开始的重试序号。
- `endpoint_id`、`target_model`、`upstream_model`：本次尝试的端点、目标模型和上游模型。
- `selected_at_ms`、`sent_at_ms`：端点选中和请求发送时间。
- `transport_returned_at_ms`、`response_headers_at_ms`、`finished_at_ms`：传输返回、响应头到达和尝试结束时间。
- `output_tokens`：本次尝试可见的输出 token 数。
- `first_token_at_ms`：本次流式尝试的首 token 延迟代理值，单位为毫秒；非流式或没有首响应记录时为空。
- `result`：尝试结果分类。
- `http_status`、`upstream_http_status`：网关和上游 HTTP 状态。
- `outbound_observed`、`outbound_event_count`：出站证据状态和事件数。
- `quality_flags`：本次尝试的数据质量标记。

## 文件二：端点配置.jsonl

一行对应一个网关端点。端点下嵌套模型、价格和容量配置。

示例：

```json
{
  "endpoint_id": "端点C",
  "deployment_type": "External API",
  "endpoint_capacity": {
    "rpm": null,
    "tpm": null,
    "concurrency": null
  },
  "observed_model_count": 34,
  "models": [
    {
      "model_id": "模型AJ",
      "observed_attempt_count": 11,
      "observed_routing_invocations": 11,
      "observed_upstream_models": [
        {"upstream_model": "模型A", "observed_invocations": 11}
      ],
      "price_config": {
        "pricing_status": "configured",
        "currency": "CNY",
        "billing_unit": "per_million_tokens",
        "price_tiers": [
          {
            "currency": "CNY",
            "billing_unit": "per_million_tokens",
            "input_tokens_min_exclusive": 0,
            "input_tokens_max_inclusive": null,
            "conditions": {},
            "input_per_million": 0.84,
            "output_per_million": 3.36,
            "cache_read_per_million": 0.084,
            "unit_price": null
          }
        ]
      },
      "capacity_config": {
        "rpm": 415,
        "tpm": 830000,
        "concurrency": null,
        "capacity_profiles": [
          {
            "supplier_id": "供应商A",
            "supplier_route_id": "路由0001",
            "rpm": 415,
            "tpm": 830000,
            "concurrency": null,
            "capacity_status": "configured"
          }
        ]
      }
    }
  ]
}
```

字段说明：

- `endpoint_id`：端点代号。
- `deployment_type`：端点类型；`External API` 表示外部 API，`Router` 表示网关内部路由入口。
- `endpoint_capacity`：端点级 RPM、TPM 和并发配置。
- `observed_model_count`：端点下的模型数量。
- `models`：该端点下的模型配置列表。
- `model_id`：模型代号。
- `observed_attempt_count`：端点和模型组合的观测尝试次数。
- `observed_routing_invocations`：可识别上游模型关系的观测次数。
- `observed_upstream_models`：上游模型及对应观测次数。
- `price_config`：模型价格配置。
- `pricing_status`：价格配置状态。
- `currency`：价格币种。
- `billing_unit`：计费单位。
- `price_tiers`：按输入区间或条件划分的价格档位。
- `input_tokens_min_exclusive`、`input_tokens_max_inclusive`：输入 token 区间。
- `conditions`：价格档位适用条件。
- `input_per_million`、`output_per_million`、`cache_read_per_million`：每百万 token 的输入、输出和缓存读取价格。
- `unit_price`：非 token 计费单位的单价，例如按张计价。
- `capacity_config`：该端点下该模型的容量配置。
- `rpm`、`tpm`、`concurrency`：请求数、token 数和并发配置。
- `capacity_profiles`：该端点和模型组合的容量档案列表；一个组合有多个档案时全部保留。
- `supplier_id`：容量档案关联代号，已脱敏。
- `supplier_route_id`：容量档案路由代号，已脱敏。
- `capacity_status`：容量档案状态。

## 数据使用

- 使用 `流量记录.jsonl` 做请求级回放和重试分析；
- 使用 `attempts` 分析端点选择、失败和重试路径；
- 使用 `端点配置.jsonl` 获取端点下的模型、价格和容量配置；
- 通过 `endpoint_id` 和 `model_id` 关联流量与端点配置；
- 通过 `capacity_profiles` 获取该端点模型对应的容量档案；
- `null` 不应按 0 处理；
- 所有标识均为脱敏代号。
